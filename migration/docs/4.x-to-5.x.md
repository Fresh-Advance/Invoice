# v4.x to v5.x Migration Guide

This document outlines special steps necessary to safely migrate from version 4.x to version 5.x of the Invoice module.
Please follow these instructions carefully to ensure a smooth transition.

## Steps

### 1. Ensure you don't use the removed placeholders in the settings

In version 5.x, certain placeholders have been removed. Go through the settings where formats are defined
and ensure all placeholders are still viable (check the help button next to the input fields).

The **<invoiceNumber>** placeholder is not available anymore. Use your current value from the invoice number format
directly where needed.
